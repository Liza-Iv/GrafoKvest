# 🎨 ГрафоКвест

**Веб-приложение для развития графомоторных навыков у детей 4–7 лет.**

> **Важно:** задания выполняются **в реальном мире** — с карандашом и бумагой. Приложение только показывает образцы, озвучивает задачи и отслеживает прогресс.

---

## ❓ Почему это важно

Многие родители думают: «Зачем специально развивать графомоторные навыки? Просто дам карандаш — пусть рисует». Но подготовка руки к письму — это гораздо больше, чем просто рисование.

Вот что на самом деле происходит, когда ребёнок учится управлять карандашом:

- **Глаза и рука начинают работать вместе** — ребёнок учится попадать туда, куда хочет
- **Карандаш ложится в руку правильно** — рука меньше устаёт, и в школе писать легче
- **Ребёнок понимает, где верх и низ, лево и право** — это помогает и на уроках, и в жизни
- **Появляется терпение и умение доводить дело до конца** — даже если задание не очень простое
- **Рука «запоминает» нужные движения** — линии становятся ровнее, штрихи — аккуратнее

И главное: графомоторные навыки — это не что-то отдельное. Всё в ребёнке связано. Когда рука становится увереннее, это помогает и вниманию, и речи, и даже учебной мотивации.

Это не просто «рисовать красиво». Это помогать ребёнку чувствовать себя успешным — уже сейчас и в школе.

### Для кого это приложение

**Для родителей:**
- Готовые задания, которые не надо искать в интернете
- Озвучка задания — ребёнок слушает и выполняет
- Прогресс сохраняется, видно сколько заданий сделано
- Можно добавить нескольких детей и переключаться между ними
- Таймер с рекомендациями по времени занятия

**Для специалистов (логопеды, дефектологи):**
- Структурированные задания с описанием что развивает каждое
- Возможность отслеживать прогресс ребёнка
- Готовые материалы для занятий

**Для детей:**
- Крупные картинки-образцы
- Озвучка задания (ребёнок слушает, а не читает)
- Звёзды за выполнение
- Праздничная награда после каждых 5 заданий

**ГрафоКвест** — это веб-приложение, которое открывается в браузере на компьютере или телефоне. Оно **не требует установки** из магазина приложений.

---

## 📱 Как это работает

1. **Родитель регистрируется** — указывает своё имя, email, пароль и имя ребёнка
2. **Открывает «Свободную игру»** — приложение показывает случайное задание
3. **Ребёнок выполняет задание** — с карандашом и бумагой, в реальном мире
4. **Родитель нажимает «Выполнил»** — прогресс сохраняется, звёзды заполняются
5. **После 5 заданий** — экран награды с кубком, конфетти и списком выполненных заданий
6. **В профиле** — видно сколько всего заданий выполнено за сегодня, за неделю и за всё время

## 🚀 Быстрый старт (локально)

### 1. Клонировать репозиторий
```bash
git clone https://github.com/ваш-логин/grafokvest.git
cd grafokvest
```
### 2. Настроить базу данных
- Установить PostgreSQL 16+
- Создать базу `grafokwest`
- Выполнить SQL-скрипты из папки `backend/db/`

### 3. Настроить пароль
В файле `backend/src/main/resources/application.properties`:
```properties
spring.datasource.password=ваш_пароль_от_postgres
```

### 4. Запустить бэкенд
```bash
cd backend
./mvnw spring-boot:run
```

### 5. Открыть в браузере
```
http://localhost:8080/index.html
```

## 📱 Установка на телефон (PWA)

1. Подключите телефон к той же Wi-Fi сети что и компьютер
2. Узнайте IP компьютера: `ipconfig` (Windows) → `IPv4 Address`
3. На телефоне откройте: `http://192.168.x.x:8080/index.html`
4. Нажмите «Поделиться» → «На экран Домой»
5. Приложение откроется как нативное (без адресной строки браузера)

## 🧩 Текущий функционал (MVP)

| Страница | Что умеет |
|----------|-----------|
| **Приветствие** | Регистрация с именем родителя и ребёнка, вход, восстановление пароля (заглушка) |
| **Меню** | Три неактивных блока (будущие задания), активный блок «Свободная игра», прогресс, таймер |
| **Свободная игра** | 15 заданий из БД, случайный выбор (выполненные исключаются), озвучка, прогресс 0/5, попап-инструкция для родителя |
| **Награда** | Кубок с анимацией, конфетти, аплодисменты, список последних 5 выполненных заданий |
| **Профиль** | Имя родителя (можно редактировать), список детей (переключение), прогресс (сегодня/неделя/всего), анимация звёздного неба, добавление второго родителя |
| **Настройки** | Звук (озвучка, скорость речи), внешний вид (контрастный режим, крупный шрифт), таймер (5/7/10/15 мин), индивидуально для каждого ребёнка |

## 🗄️ База данных (8 таблиц)

| Таблица | Назначение |
|---------|-----------|
| `users` | Родители и специалисты (имя, email, хэш пароля, роль) |
| `children` | Дети (имя, возраст, привязка к родителю) |
| `tasks` | 15 заданий (заголовок, текст, картинка, сложность, подсказка) |
| `progress` | Выполненные задания (привязка к ребёнку и заданию, дата) |
| `family_members` | Дополнительные члены семьи (папа, бабушка) |
| `settings` | Настройки для каждого ребёнка (звук, шрифт, тема, таймер) |
| `activity_log` | Журнал действий (регистрация, вход, выполнение заданий) |

## 📚 API (11 эндпоинтов)

| Метод | URL | Назначение |
|-------|-----|-----------|
| POST | `/api/auth/register` | Регистрация нового пользователя |
| POST | `/api/auth/login` | Вход (возвращает JWT-токен) |
| GET | `/api/tasks` | Получить все 15 заданий |
| GET | `/api/profile` | Профиль родителя + список детей + семья |
| POST | `/api/profile/child` | Добавить ребёнка |
| POST | `/api/profile/family` | Добавить члена семьи |
| PUT | `/api/profile/update-name` | Изменить имя родителя |
| PUT | `/api/profile/update-child` | Изменить данные ребёнка |
| GET | `/api/progress/{childId}` | Прогресс ребёнка (сегодня, неделя, всего) |
| POST | `/api/progress/{taskId}?childId=` | Сохранить выполненное задание |
| GET/POST | `/api/settings/{childId}` | Получить/сохранить настройки ребёнка |

## ♿ Специальные возможности

| Режим | Как включить |
|-------|-------------|
| **Контрастный режим** | Настройки → Внешний вид → Цветовая схема → «Контраст» |
| **Крупный шрифт** | Настройки → Внешний вид → «Крупный шрифт» |
| **Без анимаций** | Включено автоматически если в системе настроено «Уменьшение движения» |
| **Screen reader** | Все кнопки и элементы имеют `aria-label` и `role` |
